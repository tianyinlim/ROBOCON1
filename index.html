Current command STOP

Hold a direction button. Release to send STOP. Tap STOP at any time to cancel the current command.

Hardware test: With the current Basic V1 micro:bit firmware, these commands display arrows on the micro:bit LEDs only. Motor movement is disabled until the ROBOSCHOOL driver wiring and control pins are verified.

Requires Android Chrome and an HTTPS address (GitHub Pages works). Leave the official micro:bit app disconnected while using this controller. Bluetooth disconnection, lost touch, or switching away from the page resets the controller to STOP. The micro:bit must independently stop on a lost connection or missing commands.
